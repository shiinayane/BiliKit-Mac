# BiliKit 路线图

## 产品目标

为 Mac 设计的原生、克制、非官方 B 站浏览与播放客户端。不复制网页全部功能，而是让发现内容、进入
视频、连续观看和返回来源发生在一个稳定的 Mac 窗口里。观看有两条路线：

```text
发现：首页推荐／热门／搜索／稍后再看／观看历史／收藏夹 → 同窗口视频页
      → 播放 + 字幕 + 弹幕 + 分 P + 只读评论 → 相关推荐连续观看
深入：视频页的 UP 主 → 侧栏上的 UP 主空间 → 按投稿连续观看同一创作者，视频不中断
两条路线共同：登录后自动同步服务端观看进度 → 返回并恢复来源上下文
```

两条路线都已成立。UP 主空间第一版只有投稿列表；合集由视频页侧栏的选集承载。

## 当前能力

每项一行；行为细节以代码与测试为准，模块与决定见 [`ARCHITECTURE.md`](ARCHITECTURE.md)。

- 浏览：首页个性推荐（走 B 站 App 端接口，登录时按账号推荐、未登录也一样走 App 端；过滤商业推广与非视频条目；卡片显示的
  播放与弹幕数、发布时间从卡片文字解析，认不出时不显示，没有点赞数）、热门、搜索（起始页的本机搜索历史与 B 站热搜、系统联想
  菜单，匿名、无开关）；各入口保留自己的工作集与滚动位置。
- 资料库（登录后）：观看历史、稍后再看（排序、筛选与关键词）、收藏夹（侧栏逐个列出，夹内按页翻页、
  排序与搜索）；打不开的条目显示为标明原因的不可用卡片。不做“播放全部”。
- 播放：单一 player host，自动画质（HEVC 覆盖全部档位时用 HEVC，含 8K，起播失败时改用 AVC；否则用 AVC；屏幕能显示 HDR 时加入 HDR 真彩或杜比视界一档，设置里可关；音质在 AAC 各档之间随网速切换，杜比音频按输出设备自动选择，打开“无损音频”后带宽足够时播放 Hi-Res）、seek、倍速、系统字幕与音轨菜单、弹幕（含大会员彩色弹幕；B 站标记的高赞
  弹幕开头带与文字同色的赞图标，不显示赞数、无开关；合并重复弹幕默认开，同一位置、内容相同、组首后 4 秒内
  的弹幕只显示组首一条，正文右侧的深色胶囊白字计数从第二条到达起出现、每到一条直接加一，
  顶部与底部弹幕按正文居中、胶囊挂在右边；不跨分段、不跨组累计）、Now Playing、全屏与 PiP、键盘
  快捷键；游客可选 720P／1080P，登录用户按账号权限取流。
- 互动弹幕：评分、投票与关联视频在对应时间显示为半透明黑底卡片（按数据给的位置与时长，随弹幕开关，不随弹幕透明度，
  画中画不显示）；评分与投票只读，登录时标出自己的选择；关联视频卡片显示封面与标题，点击在应用内打开，与评论里的视频
  链接同一导航；UP 主在自己视频里发的弹幕照常滚动，带粉色“UP主”标签与黑底，不参与重复合并；不做关注引导与提交。
- 视频页：主区固定，侧栏承载简介、分 P、只读评论（排序、分页、楼中楼、图片、受控外链）；简介与评论里的
  站内链接、@ 与时间戳在应用内打开或跳转；相关推荐横排。楼中楼按页码直接跳页，翻页、收起后停在这一楼；回复别人的
  回复可「查看对话」，面板原地换成按楼层排列的那串对话（不缩进，不做树状），「返回全部回复」回到原页。
- UP 主空间（未登录也可）：作为侧栏上下文层打开，按投稿连续观看，视频不中断。投稿走 B 站 App 端接口（网页接口匿名时
  会被间歇风控），排序只有最新发布与最多播放，滚动到底自动加载下一批、不能跳页；顶部浮动的一行是返回按钮与空间内
  搜索框（回车搜索，结果按发布时间倒序、搜索时不显示排序，清空或 Esc 回到投稿列表并重新加载）；第一批失败时头部下方
  给说明与重试，下一批失败时列表底部给说明与重试，已显示的投稿留着。
- 稍后再看的加入与移除（登录后，用户发起）：可播放卡片的右键菜单与读屏操作里「添加到稍后再看」，稍后再看页「从
  稍后再看移除」（失效视频也可以）与 ⌘⌫；不确认、不撤销，失败放回原位，结果在窗口底部的胶囊里说明；写入不重试、
  不排队、不保存。
- 收藏（登录后，用户发起）：可播放卡片的右键菜单与读屏操作里「收藏到…」，面板列出自己的收藏夹并勾选当前归属，
  确认后一次提交差异（第一版不新建收藏夹）；收藏夹页「从此收藏夹移除」（失效视频也可以）与 ⌘⌫，失败放回原位；
  不确认、不撤销，结果在窗口底部的胶囊里说明，写入不重试、不排队、不保存。
- 点赞、投币、三连（登录后，用户发起）：播放页工具栏一组点赞、投币、收藏按钮（图标加计数，做过的实心）；点赞点一下完成、
  再点撤回（Q），投币打开面板选 1／2 枚（默认 2 枚，转载或只剩 1 枚时 1 枚，可同时点赞，W），收藏打开「收藏到…」（E），
  长按 Q 1 秒三连；全屏下 W／E 只提示先退出全屏；未登录时按钮禁用、计数照常。点赞、投币、三连走 B 站 App 端接口（网页接口
  会对部分账号或稿件拒绝第三方客户端），互动状态的读取仍走网页。结果在窗口底部的胶囊里说明，写入不重试、不排队、不保存；
  仍被 B 站以账号异常（-403）拒绝时，胶囊说明可在网页上完成并给出「在浏览器中打开」。
- 关注 UP 主（登录后，用户发起）：播放页侧栏 UP 主行显示粉丝数与投稿数（名片读到时的数，关注后不在本地增减），名字行右侧
  「关注」／「已关注」按钮点一下关注、再点取消关注；不确认、不撤销，先改按钮、失败放回，结果在窗口底部的胶囊里说明，写入不重试、
  不排队、不保存；未登录或还没读到关注状态时按钮禁用、计数照常，自己的视频不显示按钮。不做关注分组、悄悄关注与拉黑。
- 不感兴趣（登录后，用户发起）：首页推荐卡片的右键菜单与读屏操作里「不感兴趣 ▸」，原因是卡片自己给出的那几个（如「UP主:某某」
  「此类内容过多」「推荐过」「这个内容」，原样显示中文），不提供卡片里同时给出的举报类「反馈」；卡片留在原位、变暗并标「将减少此类推荐」，不能进入播放，菜单里可「撤销不感兴趣」；刷新推荐后只有仍在
  推荐里的卡片保持标记，其余的不能再撤销。不确认，失败放回，结果在窗口底部的胶囊里说明，写入不重试、不排队、不保存。
- 视频卡片菜单：各来源的卡片右键菜单与读屏操作同源，提供拷贝链接与在浏览器中打开。
- 播放器动作菜单（原生控制条的动作菜单，全屏下在「»」→「其他」里）：添加到稍后再看；拷贝链接（多 P 带分 P，开头与片尾
  5 秒外带当前时间）、拷贝 BV 号、在浏览器中打开（带同样的时间并暂停应用内播放）；“播放结束后”单选不循环（默认）、单集循环、
  自动连播、列表循环，设备级偏好。连播先按分 P，再按合集当前分部的下一集，不进入相关推荐；列表循环回到分部第一集或 P1；
  充电试看播完一律停下；下一集无法播放时停下并说明。
- 账户：用 B 站 App 扫电视端二维码登录，网页 Cookie 与 App 端令牌一次拿到、存进钥匙串里同一份凭据；启动时离到期不足 30 天、
  或页面遇到登录失效后复核时自动续期，失败不改变登录状态；只有首页推荐与「不感兴趣」、点赞、投币、三连与 UP 主空间投稿走 App 端，播放、弹幕、评论、关注等仍走网页；
  登录播放自动同步观看进度（无开关，失败不影响播放）。
- 实验能力：显式播放线路选择与测速。
- 分发：Developer ID 签名公证 DMG + Sparkle 更新；1.0.1 起仅 Apple Silicon。

## 非目标

- 下载、转码、媒体导出和离线媒体库；直播；多账号。唯一例外：评论图片预览里由用户逐张保存原图。
- 区域解锁、DRM 绕过或权限规避。
- 点踩、发动态等写操作；关注只做“当前能力”里的关注与取消关注；评论与弹幕的写入只做“当前阶段”已排期的范围；“当前能力”与排期之外的账户写入，
  包括批量管理、清空稍后再看或清除已看完、手动排序、重命名或删除收藏夹、在收藏夹之间移动或复制。
- 自研更新器、自动降级、Cloudflare 下载或 B 站代理。
- 为减少加载而引入通用 Cache、数据库或 Shared Store。

## 界面原则

- 使用系统窗口、侧栏、toolbar、菜单、focus 与辅助功能行为，不复制网页导航或播放器控制条。
- 首页推荐与热门语义不同，不互相冒充；每个入口的状态、分页与滚动独立，不共享可互相污染的页面状态。
- 状态诚实：加载、失败、登录限制准确呈现；刷新失败不清空仍可用结果；不伪造内容，不用登录诱导代替错误。
- 视频页是同窗口层级导航，返回恢复来源；切换分 P 不增加层级。播放器是主区稳定锚点，resize、全屏、
  PiP、返回与媒体替换都不创建第二个 player host。
- 侧栏在播放态由单一滚动 owner 组织简介、分 P 与评论；评论加载、图片与外链不控制播放器。
- 相关推荐不自动播放、不无限循环。外链只在用户点击后经严格解析再打开。
- BiliKit 特有 action 必须有明确用户结果，不因 API 存在就加浮层。
- VoiceOver、Full Keyboard Access、动态文字和高对比度需真人验证；截图和 AX tree 不构成验收。

## 范围变更

新页面、写操作、持久化或自定义播放器 UI 需先说明解决的真实空白、失败时页面是否仍成立、owner 与
清理点，再更新本文。不以占位 target、预留 UI 或未调用抽象提前进入工程。
