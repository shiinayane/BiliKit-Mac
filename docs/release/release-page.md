## 安装

下载下方 DMG，打开后将 BiliKit 拖入“应用程序”，再启动。已安装的用户可通过应用菜单“检查更新…”获取新版。

包含推荐、热门、搜索、二维码登录、观看历史同步、视频播放、分 P、字幕、弹幕、只读评论和相关推荐连续观看。

安装包已完成 Developer ID 签名与 Apple 公证。

BiliKit 为非官方第三方项目，与哔哩哔哩无隶属关系。
