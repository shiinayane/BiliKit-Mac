- 改善 macOS 27 下评论时间、属地及点赞信息的可读性。
- 播放器控件采用系统默认样式，并修正 Xcode 27 API 兼容问题。
- 播放改用 B 站现行取流接口；未登录时也可选择 720P／1080P。
- 修复“播放线路”测速始终失败的问题；被 B 站限制时会给出明确提示。
- 搜索请求补齐 B 站要求的参数，减少被拒绝的情况。
- 视频分段改为边下载边播放，降低播放时的内存占用。
- 修复网格在刷新或重新搜索后无法自动加载更多的问题。
- 修复热门、搜索翻页时登录已失效却没有提示的问题。
- 修复登录状态复核被中断时误显示“未登录”，以及切换账号后观看历史停在加载中的问题。
- 修复播放器在其他控件获得键盘焦点时仍抢占方向键和空格的问题。
- 评论图片预览与侧栏加载状态改用系统样式。
- 从此版本起，仅支持 Apple Silicon（M 系列芯片）Mac，系统要求仍为 macOS 15 或更高版本。
- 1.0.0 是最后一个支持 Intel Mac 的 Universal 版本；Intel 用户请继续使用 1.0.0。
