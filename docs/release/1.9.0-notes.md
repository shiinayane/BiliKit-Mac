- 登录后侧栏新增「关注」：看全部关注、特别关注与各个分组，每组带人数；全部关注可以按最近关注或最常访问排序，也可以在关注中搜索。
- 可以把 UP 主加入或移出特别关注、设置分组：点「已关注」弹出这些选项，关注页的卡片右键也有。
- 在播放页侧栏的 UP 主预览里点“打开完整空间”，右侧打开整页 UP 主空间；在空间里点投稿接着看，返回时逐层回到原来的视频，被盖住的视频会暂停、回来接着播。
- 新增“前往”菜单：⌘[ 返回上一页，⇧⌘H 回到当前来源的列表；点侧栏里当前高亮的那一行也会回到列表。
- 进出播放页与空间页加上转场动画，返回时页面连同视频画面一起滑走。
- 画中画播放时打开空间页，视频继续播放；点画中画的“还原”回到播放页。
- 侧栏收藏夹显示各自的条数，收藏或移除后立即更新。
- 评论里的时间戳按网页评论区的规则识别，2#01:23 这样的时间戳会跳到第 2 个分 P；修复播放器准备好之前显示的评论里时间戳一直不能点的问题。
- 提示更清楚：全屏时点赞、三连、加入稍后再看的结果（包括失败原因）显示在播放器上；一次操作只提示一次；发评论成功后也会提示；播放器上的说明停留更久，可以折成两行。
- 开着 VoiceOver 时，会读出“已从上次看到的位置继续播放”和试看结束的说明。
- 修复单集循环有时播完不重播的问题。
