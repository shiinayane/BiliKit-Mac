# M4.5 高刷新率卡片滚动观察（2026-07-24）

## 结论

在 4K、最高 240 Hz 外接屏上的受控对照中，热门卡片流没有主线程 hang，60 Hz 预算
充足、120 Hz 大体可用，但真实封面与头像纹理的合成成本不足以稳定填满 240 Hz。

移除渐变、圆角、描边和头像遮罩没有收益；改用占位色后 GPU 中位耗时明显下降；降低
图片插值质量同样没有收益。因此当时没有牺牲现有视觉，也没有引入通用图片框架或缓存层。

## 适用边界

这是特定显示器、系统和当时实现的性能观察，不是当前性能保证，也不构成图片 pipeline
的实施授权。

只有真实日用仍能稳定复现高刷观感问题，且优先级高于产品闭环时，才建立独立、有限的
图片呈现性能切片。候选可以比较当前 `AsyncImage`、AppKit/`CALayer` layer-backed
图片宿主，以及有证据需要时的预解码缓存；验证必须同时覆盖滚动帧成本、图片替换与取消、
内存上限、失败占位和离屏清理。
