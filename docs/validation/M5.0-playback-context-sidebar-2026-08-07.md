# 播放上下文侧栏边界

播放页继续使用同一个系统 `NavigationSplitView` sidebar 和一个 `AVPlayerView` host。侧栏只
展示真实简介、UP 主、分 P 与“评论尚未接入”状态；不伪造评论或推荐数据。

分 P 切换只替换媒体 identity，不增加导航层级。请求中 identity、已呈现 identity、
generation、取消、失败重试和 reset 由既有 Coordinator/ViewModel/Playback owner 管理。
替换视频时旧侧栏内容不可交互并从辅助阅读路径隐藏；Back、关窗或登出后清理播放项、
observer、字幕、弹幕与临时媒体资源。

分 P 行保留真实用户语义：完整 label、selected trait，以及 loading/failure/retry 状态。
简介和签名保持可选择；展开控件使用原生 `DisclosureGroup`/`Button` 语义。自动化 identifier、
synthetic sidebar、测试专用播放器、透明状态 probe 和 XCUI 层级断言不属于产品契约。

状态、identity、generation、失败和清理由 unit/integration tests 验证。真实窗口 resize、
AVKit 控件、VoiceOver 阅读顺序和 Full Keyboard Access 焦点顺序需要分别进行当前产品观察；
build、AX tree、fixture 或截图不能替代这些结果。
