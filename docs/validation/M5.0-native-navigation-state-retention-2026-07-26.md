# M5.0 原生导航与日用状态保留验证记录

日期：2026-07-26（Asia/Tokyo）

状态：进行中，不关闭 M5.0 Gate。

## 本次范围

- 用 macOS 15 `TabView(.sidebarAdaptable)` 表达三个平级来源栏目，每个 Tab 内用
  `NavigationStack(path:)` 替代 App 自定义 `AppRoute`／`AppReturnSnapshot`。
- 以类型化 `PlaybackDestination` 表示播放 destination；path pop、侧栏切换和关窗
  统一经过同一个播放副作用 owner。
- 热门与最后搜索保留两份有界窗口内工作集，包含内容和请求状态；各 Tab 直接读取自己
  的 presentation，合计最多一个 active request。App shell 为热门、搜索和历史各持有
  一个以视频 identity 为目标的原生 `ScrollPosition`，不再由 ViewModel 另存数值
  offset。
- 删除卡片 `isSelected` 参数、selected 边框、辅助功能 trait 和无颜色区分 checkmark；
  hover、press、keyboard focus 样式保留。
- 普通激活不重复请求；显式刷新保留旧内容，刷新失败不清空同 identity 内容；关窗
  reset。

未增加 endpoint、认证、持久化、通用 cache、图片 pipeline 或媒体缓存。
