## 保存原则

- 保存能说明真实设备、网络、签名、安全或系统行为的记录。
- 不保存逐轮计划、任务分工、临时清单和已经被代码现状取代的状态表。
- 带日期证据只证明当时列明的环境与样本，不自动证明当前构建或全部用户路径。
- 删除的过程稿仍可从 Git 历史恢复；需要重新裁决时，应先核对当前代码和官方资料。
